# Handoff Rules

Read README.md first. This is a kinematic reference generator, not robot control.
Use the pinned included VICAR visual URDF; do not substitute Thor/YAM or mount a
second racket. Do not assume collision/inertia elements exist in this model.
Never stream these arrays to hardware without separate dynamics/safety checks.

Keep example motions immutable. Generate experiments in outputs/. Retain the
1 s impact, 50 Hz sampling, fixed root/legs, mostly-static left arm, right
shoulder roll upper bound -0.3 rad and exact return to ready pose unless asked
otherwise. Coordinates: +X forward, +Y left, +Z up, metres/radians, WXYZ root
quaternions. Sliders are Y/Z offsets, NOT X/Z. X is fixed at 0.43 m in the grid.
Camera controls must remain user-controlled during playback and selection.

Run `uv run --extra test pytest -q` and `uv run python scripts/validate_bundle.py`
after changes. Inspect actual FK, not just saved validation metadata. Preserve
strict pose checks; do not silently replace unreachable targets with neighbors.
Full-grid optimization can be slow; use one motion for a smoke test first.
Do not overwrite provenance or claim every stored motion was regenerated by the
current script: the included grid retains its original per-motion solver hashes.

No cluster access, GR00T checkout, SONIC checkpoint, Isaac Sim or hardware is
required. Do not introduce such dependencies. Never copy secrets into this repo.
